同時視聴タイマー プライバシーポリシー

制定日: 2026年10月20日 / 更新日: 2026年10月24日

Chrome 拡張機能「同時視聴タイマー」(以下「本拡張機能」)が扱う情報と、その扱い方を説明します。

外部への送信はしません

本拡張機能は、読み取った情報や設定を開発者や第三者のサーバーへ送信しません。広告・アクセス解析・トラッキングの仕組みも使っていません。

例外として、利用者が「OBS 連携」を有効にした場合に限り、利用者が設定した OBS Studio の WebSocket サーバー(通常はこのパソコン上の 127.0.0.1)へ、表示に使う時刻・タイトル・再生状態とデザインの設定を送ります。OBS につながっている他のツールにも届くことがあるため、動画ページの URL と OBS のパスワードは送りません。

読み取る情報

情報目的
開いているタブの URL とタイトル動画のあるタブを探し、表示対象の候補として一覧に出すため
動画ページの動画のタイトル・話数・再生時刻・再生状態タイマーに表示し、OBS へ出力するため
パソコンに入っているフォントの名前(利用者が読み込みを許可した場合のみ)表示に使うフォントを一覧から選べるようにするため

本拡張機能は、利用者の操作に応じて動画の再生・一時停止・再生位置の移動を行います。ページ内のそれ以外の内容を読み取ったり変更したりはしません。

保存する情報

次の情報を、このブラウザの拡張機能用ストレージ(chrome.storage.local)に保存します。保存先はこのパソコンのブラウザ内だけです。

  • 表示・デザイン・カウントダウン・OBS 連携の設定
  • OBS 連携のパスワード(利用者が入力した場合。暗号化はしていません)
  • 動画ごとの「0点」(動画ページの URL と、0:00 にした再生位置。新しいものから最大30件)
  • デザインのプリセット
  • 見る人用の時刻ジャンプの補正秒数

これらは本拡張機能をブラウザから削除すると消去されます。

第三者への提供

本拡張機能が扱う情報を、販売・譲渡・共有することはありません。信用力の判断や融資の目的にも使いません。

このポリシーの変更

本拡張機能の動作を変えるときは、このページを更新し、制定日の下に更新日を記載します。
